Action Voice JP v0.3.0 (実験版)
==============================
FF14/Dalamud API 15用ソースコード。未ビルド・ゲーム内未検証。

【できること】
・人物名＋ホームワールドを登録（ターゲットから取得可能）
・人物ごとのアクションID／WAV／音量／遅延を登録
・自分のPCだけで音声を別再生。既存SE/VFXファイルには干渉しない
・人物ごとのボイスパックZIPの出力／読み込み

【最重要：まだできないこと】
・フレンドの無詠唱アクション（例：機工士ドリル）の検知は未実装。
・他人の『詠唱あり』アクションの開始のみ、可視範囲内で試験的に検知。
・他人の無詠唱技にはアクション効果イベントを正確に取る機能が別途必要。
・この段階で『ドリルにフレンドの声が付く』とは言えません。
・ゲーム内での実動作やビルド成功はまだ確認していません。

【ビルド】
1. Visual Studio Community 2026でActionVoiceJP.csprojを開く。
2. .NET 10 SDKとDalamud開発環境を用意する。
3. Releaseでビルド。エラーがあれば記録し修正。
4. Dalamudの開発プラグインとして読み込む。

【操作】
・コマンド /actionvoice でUIを開く。
・フレンドをターゲットして『ターゲットから追加』。
・キャラを選び『ボイスを追加』、アクションIDを入力。
・VoicesフォルダーにPCM WAVを置く。
・『音声一覧を更新』→『音声を選ぶ』→『試聴』。
・『選択中の設定をZIPに出力』するとVoicePacksにZIP作成。
・受け取った人は『インポートZIPのフルパス』欄にZIPパスを貼り付けて読み込む。
・読み込みは既存人物の上書きではなく追加。必要なら古い人物設定を手動削除。
・ZIPに声ファイルも含むので、配布に権利・許諾がある音声だけ共有してください。

【安全上の配慮】
・ZIPは自動実行なし、JSONとWAVのみ。
・ZIP内のパスを直接抽出先に使わない方式でパストラバーサル対策。
・インポート容量はWAVごと30MB、最大200件。
・声はWindowsのMCI機能で再生するため、ゲーム内音量と独立。
・ゲーム側のバージョンやDalamud API変更で修正が必要になる場合があります。
・サードパーティ製プラグインにはFF14利用規約上のリスクがあります。

【試聴停止】
「▶ 試聴」で再生した音声は「■ 試聴停止」で途中停止できます。
ゲーム内のアクション連動音声は停止対象ではありません。

【新機能：使った技からアクションIDを取得】
1. /actionvoice で設定を開き、登録先の人物を選択。
2. 「● 測定開始」を押す。
3. 自分のキャラクターで技を使用する。
4. 履歴にIDが表示されるので「新規ボイスに登録」、または「選択中に設定」。
5. 「■ 測定停止」を押す。
自分のアクション使用要求だけを記録します。フレンドが使った技は記録できません。
ボタン押下時の使用要求の成否・タイミングにはゲーム側の差があり、ゲーム内動作は要検証です。
検出したIDをフレンドのプロフィールのボイスルールへ登録することはできますが、
フレンドの無詠唱アクションを鳴らす仕組みはまだ未実装です。

【更新方法】
・FF14側でプラグインを無効化し、Visual Studioを閉じる。
・既存ActionVoiceJPフォルダのコード一式をバックアップ。
・本ZIPのActionVoiceJPフォルダ内ファイルを既存プロジェクトへ上書き。
・Plugin.csに旧バージョンで手動追加したUseActionModeのusingがあれば、
  このバージョンには既に含まれるので二重追加しない。
・Visual Studioで再ビルドし、Dalamud側で再読み込み。
・キャラクター設定はDalamudのpluginConfigsに保存されるので原則引き継がれます。
