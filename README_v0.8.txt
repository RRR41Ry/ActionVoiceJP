Action Voice JP v0.8 — ジョブ表示・ビルドエラー修正版

変更点
・MainWindow.csで重複した name 変数（CS0136）を actionName に変更
・Plugin.cs の UseActionMode の型エイリアス維持
・登録済みのジョブと現在選択中のジョブだけボタン表示。画面幅で折り返し
・ジョブ選択のリセット不具合（共通へ戻る）を修正
・「ジョブを追加・切替」から未登録ジョブを選択可能
・サモン・カーバンクル(ID 25798)を召喚士として扱う
・ActionシートのClassJob情報に基づき、判定可能な技はジョブを自動分類
・既存の「共通」アクションを初回更新時に可能な範囲で自動移行
・未知のIDや複数ジョブ共用技は誤分類しないため「共通」に残す

手順：前版のソースフォルダをバックアップ→本zipのActionVoiceJP内のソースを上書き→Visual Studioでビルド→Dalamudで再読込。

注意：C#コンパイルとゲーム内動作はこの環境では未検証です。
フレンドの無詠唱アクションの自動検知は引き続き未実装です。
