## 📥 インストール方法 / Installation

### 🇯🇵 日本語

Action Voice JPは、Dalamudのカスタムプラグインリポジトリからインストールできます。

**導入手順**

1. FF14を起動し、チャット欄に `/xlsettings` と入力します。
2. 「試験的機能（Experimental）」タブを開きます。
3. カスタムプラグインリポジトリの一覧に、以下のURLを追加します。
4. 「Enabled」にチェックを入れ、「Save」を押します。
5. チャット欄に `/xlplugins` と入力します。
6. プラグインインストーラーで「Action Voice JP」を検索します。
7. 「インストール」を押して導入します。

**カスタムリポジトリURL**

```text
https://raw.githubusercontent.com/RRR41Ry/ActionVoiceJP/main/repo.json
```

インストール後は、ゲーム内チャットで以下のコマンドを入力してください。

```text
/actionvoice
```

Action Voice JPの設定画面が開きます。

※ リポジトリURLは配布準備完了後に利用可能になります。

---

### 🇬🇧 English

Action Voice JP can be installed through a custom Dalamud plugin repository.

**Installation Instructions**

1. Launch FFXIV and enter `/xlsettings` in the chat.
2. Open the **Experimental** tab.
3. Add the following URL to the custom plugin repositories list.
4. Enable the repository and click **Save**.
5. Enter `/xlplugins` in the chat.
6. Search for **Action Voice JP** in the plugin installer.
7. Click **Install**.

**Custom Repository URL**

```text
https://raw.githubusercontent.com/RRR41Ry/ActionVoiceJP/main/repo.json
```

After installation, enter the following command in the game chat:

```text
/actionvoice
```

This opens the Action Voice JP configuration window.

**Note:** The repository URL will become available once the public release is ready.
