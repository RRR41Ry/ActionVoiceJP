Action Voice JP v0.5 UI 改善版（未ビルド・未実機検証）

変更点:
・測定履歴を「日本語アクション名 | ID」で表示。
・検出した技を新規登録すると、表示名も自動設定。
・登録済みアクションは折りたたみ式。見出しを押すと開閉。
・アクション名・IDの簡易検索。
・各技の設定は開いた項目だけ表示。
・既存のキャラクター設定/試聴/音量機能は維持。
・UseActionModeエイリアス修正維持。

更新方法:
1. FF14内でプラグインを無効化
2. プロジェクトをバックアップ
3. このZIPのActionVoiceJP内ファイルを元プロジェクトに上書き
4. Visual Studioでビルドし、Dalamud開発プラグインをリロード

注意:フレンドの無詠唱アクション検知にはまだ対応しません。
