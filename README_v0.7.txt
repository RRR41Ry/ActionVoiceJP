Action Voice JP v0.7 — ジョブ別タブ

・キャラクターごとに共通／戦士／召喚士などのタブを表示します。
・選んだジョブに新規ボイスや測定履歴のアクションを登録します。
・既存のアクション設定は自動で「共通」に表示されます。削除しません。
・各ボイスの「ジョブ分類」で別タブへ移動できます。
・共有ZIPの設定にはジョブ分類も含まれます。以前のZIPは「共通」に表示されます。

注意：ジョブタブは設定の整理用です。アクション再生の条件は従来どおりアクションIDとキャラクターで判定します。
フレンドの無詠唱アクション検知はこの版でも未対応です。

ビルド: Visual Studio 2026 で ActionVoiceJP.csproj を開き Ctrl+Shift+B。
ビルド・ゲーム内動作確認は未実施です。
